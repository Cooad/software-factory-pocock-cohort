# Cadence

Cadence sells video courses to learners. This glossary covers the language around getting money back after a purchase.

## Language

### People

**Admin**:
A user with the admin role. Admins run Cadence and are the ones who decide Refund Requests.
_Avoid_: The team, Staff, Support (and never Team, which is a group of learners sharing Seats)

### Enrollments

**Enrollment**:
A learner's place on a course, which gives them access to it. A learner can have several Enrollments in one course over time, but at most one Active Enrollment.

**Active Enrollment**:
An Enrollment that currently gives the learner access to the course.

**Revoked Enrollment**:
An Enrollment that no longer gives access, kept as history along with any completion. Buying the course again creates a new Enrollment rather than restoring a revoked one.
_Avoid_: Ended, Cancelled, Withdrawn, Expired

**Revocation Reason**:
Why an Enrollment was revoked. Today the only reason is an Approved Refund Request.

### Team purchases

**Seat**:
One place in a course bought for a Team, handed to a teammate as a code they redeem. A claimed Seat belongs to the Team and can't be refunded.
_Avoid_: Licence, Coupon (for the place itself)

**Held Seat**:
An unclaimed Seat that can't be redeemed because its purchase has an Open Refund Request. It is released if the request is declined and stops working for good if it is approved.
_Avoid_: Frozen, Locked, Suspended

### Refunds

**Refund Request**:
A learner's ask, with their reason, to get back what they paid for a purchase. An Admin approves or declines it. One purchase can have several Refund Requests over time, but only one can be undecided at once.
_Avoid_: Refund (for the ask itself), Cancellation, Reversal, Chargeback

**Open Refund Request**:
A Refund Request no Admin has decided yet.
_Avoid_: Pending, Requested, Awaiting review

**Approved Refund Request**:
A Refund Request an Admin has accepted. Approving it ends the learner's access to the course and leads to a Refund.

**Declined Refund Request**:
A Refund Request an Admin has turned down. It has no Refund, and the learner may raise a new Refund Request.

**Decision Note**:
The Admin's explanation of why they approved or declined a Refund Request, shown to the learner. Optional on approval, required on decline.
_Avoid_: Reason (that is the learner's own words), Comment, Response

**Refund**:
The money returned to a learner after their Refund Request is approved. It is always the full amount they paid. A declined Refund Request has no Refund.
_Avoid_: Reversal, Chargeback, Cancellation

**Pending Refund**:
A Refund where the money hasn't been confirmed as sent yet.
_Avoid_: Pending (for a Refund Request awaiting review)

**Issued Refund**:
A Refund where the money has been confirmed as sent back to the learner.
_Avoid_: Completed, Paid out

**Failed Refund**:
A Refund where the money couldn't be sent. The Refund Request stays approved, because the decision hasn't changed. An Admin can retry it, which makes it a Pending Refund again.
